No Stairs Please Remote MCP Server

Every small stage in all 50 states, and who books it. The No Stairs Please MCP server lets gigging musicians, solo acts, and tour managers query live music venue booking data directly inside Claude, ChatGPT, and Gemini.

What the Server Covers

Independent bands spend hours digging through outdated spreadsheets and social pages to find who books a 150-capacity room in another state. The No Stairs Please venue directory tracks 38,223 open rooms across all 50 US states, the District of Columbia, and British Columbia. Each room record separates the talent buyer or booking contact from general event rentals, notes which nights the room runs live music, lists room capacity and stage notes, and tracks recent show history.

Connection Details

  • Endpoint: https://nostairsplease.com/mcp
  • Transport: Stateless Streamable HTTP
  • Authentication: OAuth 2.1 with Dynamic Client Registration
  • Server Card: https://nostairsplease.com/.well-known/mcp/server-card.json

Available MCP Tools

Tool Name What It Does
search_venues Search live music venues by state, town, category, room capacity, music day, or text query.
get_venue Read the venue record for a single room by ID.
reveal_venue Spend one free reveal to unlock the full venue record and booking contact for 7 days.
find_by_performer Find rooms where a band or solo performer has played or is scheduled to play.
get_profile Inspect the signed-in account tier, All Access status, and remaining free reveals.
list_saved_venues List the signed-in account's favorite venues.
save_venue Add a venue to the signed-in account's favorites list.
remove_saved_venue Remove a venue from the signed-in account's favorites list.

Client Configuration Example

Add the remote Streamable HTTP endpoint to any MCP-compatible client and sign in through the OAuth 2.1 consent flow:

{
  "mcpServers": {
    "nostairsplease": {
      "type": "http",
      "url": "https://nostairsplease.com/mcp"
    }
  }
}

Tour Routing Workflows

Instead of building a route one city at a time in separate browser tabs, you can ask an AI assistant to filter rooms along a drive corridor, compare capacities against your draw, and check where similar touring acts played in the last 90 days. Once you have a shortlist of rooms, save them to your account favorites and reveal the booking contacts you plan to email.

Free accounts start with no card needed and include monthly venue reveals. One-time All Access passes ($25 for one month or $200 for one year) unlock unlimited venue records across both the website and the MCP server.
